# GrowingAnttisNeuron

**Grow the matrix first. Then ask what computation its physics makes possible.**

GrowingAnttisNeuron is a developmental testbed for AnttisNeuron. The first target is deliberately small: fixed dendritic target arbors, branching axonal growth cones guided by smooth chemoaffinity-style molecular fields, proximity-and-compatibility synapse formation, then a frozen physical graph that can be interrogated as an operator.

The project is not a claim to simulate literal neuronal development. It is an instrument for asking whether a compact developmental program can grow structured connectivity that changes the modal and computational properties measured in AnttisNeuron.

See `docs/superpowers/specs/2026-09-14-developmental-anttisneuron-design.md` for the v0 design once added.
