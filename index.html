v1 physical bridge — frozen 16-seed Python receipt

Same cable. Different place to enter it.

Guided and shuffled use identical passive cable geometry and spectra. Development can only change which dendritic compartment receives the current and therefore the modal coefficients of that input.

visible modes — guided / shuffled4.9148 / 4.9214
95% purification time — guided / shuffled675.857 / 679.523
soma transfer — guided / shuffled0.005213 / 0.003968

The mean effect is sparse, not universal. Four of sixteen seeds move the accepted guided input to a physically different relative port; most seeds remain permutation-equivalent and the paired medians are essentially zero. The cable decay spectrum itself is unchanged.

Interpretation: v1 exposes an input-placement effect, not a spectral advantage.

v2 operator codebook — frozen 16-seed Python receipt

Same grown network. Different physical kinds of receiver.

v2 grows the organism once per seed, then compiles the same axons, synapses, weights and contacts against four dendritic scale phenotypes: 0.70, 0.90, 1.20 and 1.45. The control shuffles the exact same phenotype inventory among receiver addresses.

phenotype match — coded / shuffled1.0000 / 0.2813
operator-target error — coded / shuffled0.0000 / 0.0995
95% purification time — coded / shuffled705.601 / 696.050
soma transfer — coded / shuffled0.02730 / 0.02966

The calibration works; the functional win does not. Exact address→phenotype shuffling breaks operator compatibility while preserving the grown anatomy and material inventory. But modal visibility, purification and transfer have paired medians essentially at zero, and purification changes sign across seeds.

Interpretation: a developmental address can stand in for physical operator identity, but v2 is still an oracle codebook. The next experiment removes phenotype IDs and asks whether equal-power signals with different temporal statistics can locally grow different operators from the same initial morphology.
